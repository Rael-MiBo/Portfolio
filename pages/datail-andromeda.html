Sobre o Projeto

O Andromeda Bot é um bot desenvolvido para a plataforma Discord, projetado para facilitar a moderação de servidores e proporcionar funcionalidades divertidas para os usuários. Com comandos personalizáveis, o bot permite que administradores gerenciem membros, mensagens e canais de forma eficiente.

Além das funcionalidades de moderação, o Andromeda Bot inclui integração com a API do Banco Central com a cotação diaria. O bot é construído utilizando a biblioteca Discord.js, garantindo performance e escalabilidade.

Tecnologias Utilizadas

  • JavaScript (ES6+)
  • Node.js
  • Discord.js
  • APIs REST
  • SquareCloud (Hospedagem)

Desafios e Aprendizados

Durante o desenvolvimento do Andromeda Bot, enfrentei desafios relacionados à integração com a API do Discord e à implementação de comandos personalizados. Foi necessário estudar a documentação da biblioteca Discord.js para entender como manipular eventos e interações de forma eficaz.

Além disso, aprendi sobre boas práticas de desenvolvimento de bots, como gerenciamento de permissões e tratamento de erros. A experiência me proporcionou um entendimento mais profundo sobre desenvolvimento backend e integração com APIs externas.
